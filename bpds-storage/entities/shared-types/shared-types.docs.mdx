A component for a SharedTypes entity, supports serialization and de-serialization of SharedTypes objects and can be used from
both backend and frontend.

## Get started

Install and use the entity to create a new instance:

```ts
const sharedTypes = SharedTypes.from({
  name: 'hello'
});
```
