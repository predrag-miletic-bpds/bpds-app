A theme component for using the BpdsTokens Design Language and tokens.

## Get started

To use the BpdsTokens theme in your app, install the theme and apply it on your component tree.
Themes are usually applied on the root of your component tree.

```tsx
import { BpdsTokens } from '@scope/design.bpds-tokens'

export function MyApp() {
  return (
    <BpdsTokens>
      <Homepage />
    </BpdsTokens>
  );
}
```
